## View Orientation dialog [Cqwt0Yjst18 (SW 2013), PcvGvTBo9AA]
- **Spacebar** opens it; layout: standard views (Front, Back, Left, Right, Top, Bottom) plus the offset/isometric group; icon at the **top-left** = **New View** → small name prompt; saved custom views are listed [Cqwt 0:15–2:34; Pcqv 1:30].
- **Save** button saves the named views to the *application* (available in other documents and after restart) [Cqwt 2:34–3:34].
- The **View Selector** toggle is an icon on the dialog; Ctrl+Space shows the selector cube; clicking a cube face/edge/corner orients the view [Cqwt 0:51–1:46].
- Custom views appear in a drawing's **View Palette** (task pane) after Refresh, and can be dragged onto a drawing [PcvG 1:54–2:11].

## Hide faces while mating (2018+) [RWwnjhM2UWg 0:07–3:30]
- Active **Mate** tool: hover a face and press **Alt** to hide it; keep pressing Alt to hide successive faces behind; **Shift+Alt** shows them again one at a time. Works in new mates, edit mate, copy mates, mate identity.
- With the Width mate, outer boundary faces are picked then Alt-hide a face to reach the back face.

## Select flyout [gERKKea7t5c 0:38–4:54, rest below]
- Opened from the pull-down arrow of the **Select** tool in the top (heads-up/menu) bar; entries (in order shown): **Magnified Selection** (magnifier lens; can zoom inside the lens, pick small objects), **Box Selection**, **Lasso Selection**, **Select Over Geometry**, **Select All**, **Volume Select**, **Select Suppressed**, … (list continues).
- Box selection: left→right = completely enclosed; right→left = touched. Lasso: same rules, freeform.
- **Select Over Geometry**: lets a box/lasso window start while the cursor is over geometry (when zoomed in with no empty space); otherwise the click selects the face/edge.
- **Volume Select**: rectangle defines a 3D volume; items completely inside (or crossing, by drag direction) are selected.
- **Select Suppressed**: selects all suppressed components of the assembly.
