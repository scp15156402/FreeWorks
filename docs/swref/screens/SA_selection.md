# S-A selection behaviour  (uiGQITTUZ8k, ubQ2ZTPyCbk, 5lJYi5oDvPQ, ngrgi014WWE, 2OBhkol8Y_Q, XXcmMOrt0sw) — from transcripts
Behaviour only; frames for the toolbar/menus are in the "Frames" section if taken.

## Selection Filter toolbar [uiGQITTUZ8k]
- With any filter on, a **funnel** is shown beside the cursor (0:00–0:15). Several filters can be on at once.
- Toolbar appears where it was last positioned; default **docked lower left** (0:27). Large toolbar; toggled by **F5** (1:09). One icon **clears all filters** (1:17).
- Predefined keys: **V** vertices, **E** edges, **X** faces (0:44). Face filter makes small faces pickable even when the assembly is fitted to screen (1:25–2:00); used when mating (face-to-face).

## Box and lasso selection [ubQ2ZTPyCbk]
- Default = box selection, **direction matters**: left→right = only items fully inside (blue transparent box); right→left = items inside **and crossing** (green transparent box). Works in sketches, assemblies, drawings (0:21–0:46).
- **Lasso selection**: Tools ▸ Lasso Selection (not default) (0:55). Clockwise freeform lasso (blue) = fully inside; counter-clockwise (green) = inside and crossing (1:05–1:22).
- Multiple selections: Ctrl+box adds; Ctrl+click adds/removes single items (1:32–1:47).

## Select Other / Alt-hide faces [5lJYi5oDvPQ]
- Hover the blocking face, **right-click ▸ Select Other**; hover/right-click again to step through faces until the wanted one is highlighted, then pick (0:26–0:51). Works in parts and assemblies.
- **Alt key** (predefined; assemblies only, only while the Mate command is active): hover a face in the way and press Alt to hide it; repeat to reach deeper faces (1:12–1:43).

## Select Partial Loop / Select Chain [ngrgi014WWE, 2OBhkol8Y_Q]
- Right-click an edge end (Ctrl held, per speaker "maybe necessary") ▸ **Select Partial Loop**: picks the connected edges in the direction of the clicked end; clicking the other end picks the other direction (0:03–0:37).
- Sketch: right-click a segment ▸ **Select Chain**: selects every entity connected end-to-end (including non-tangent); Delete removes all (0:15–0:53).

## Mouse gestures + keyboard workflow [XXcmMOrt0sw]
- Gestures appear after holding the mouse ~1 s; **4 by default, up to 12 per environment**; separate sets for part, sketch, assembly, drawing (2:15–2:30). Typical mapping in sketch: line, circle, rectangle, quick dimension (2:47).
- Keyboard tab lists every function; filter shows only mapped ones (1:35–2:06). Small icons + shortcuts save screen space (3:28).
